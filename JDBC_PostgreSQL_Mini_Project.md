# JDBC + PostgreSQL Mini Project

This project builds a small console application called **Student Management JDBC**. Its purpose is to make the raw JDBC flow visible from database setup through CRUD, generated keys, batch insertion, and one atomic account transfer.

Technologies:

```text
Java 17 + Maven + JDBC + PostgreSQL
```

Not used:

```text
Spring, Spring Boot, JPA, Hibernate, web servers, REST, Docker,
or persistence helper libraries
```

> The instructions, starter shapes, TODOs, and hints come first. The complete code is intentionally delayed until section 27.

---

## 1. Project Goal

> Priority: ⭐⭐⭐⭐⭐ MUST KNOW practice

Build a plain Java console application that can:

- connect reliably to a local PostgreSQL database;
- create, find, list, update, and delete students;
- retrieve the ID generated by PostgreSQL;
- report meaningful `SQLException` details;
- insert several students with a prepared batch;
- transfer money between two accounts in one transaction;
- keep SQL/JDBC code in DAO/service classes instead of `main()`.

The final learning flow is:

```text
PostgreSQL installed/running
        ↓
role + database + tables created
        ↓
Java Maven project
        ↓
pgJDBC dependency on runtime classpath
        ↓
JDBC URL + external credentials
        ↓
Connection
        ↓
PreparedStatement + bound values
        ↓
executeQuery / executeUpdate
        ↓
ResultSet → Student objects
        ↓
try-with-resources + SQLException handling
        ↓
generated keys + batch + transaction
        ↓
working console application
```

Expected time is approximately **3–6 focused hours**, depending on PostgreSQL installation and how much code you write before consulting hints.

- Apache Maven 3.6.3 or newer;
- a local PostgreSQL server;
- `psql`, pgAdmin, DBeaver, or another PostgreSQL client;

### If PostgreSQL is not installed yet

On Windows, the simplest beginner route is the installer linked from the official PostgreSQL download page:

1. install the PostgreSQL server;
2. include command-line tools (`psql`) and optionally pgAdmin;
3. keep port `5432` unless another service already uses it;
4. set and securely record the local administrator (`postgres`) password;
5. finish installation and open SQL Shell or pgAdmin;
6. verify the service before creating the practice role/database.

On macOS or Linux, use the operating-system instructions linked from the same official page. Package names and service commands vary, but the required result is identical: a running PostgreSQL server, a known administrator login, and `psql` or a GUI client. Do not install multiple PostgreSQL distributions simultaneously unless you understand which server/port is active.

Verify Java and Maven:

```bash
java --version
javac --version
mvn --version
```

Expected essentials:


Verify PostgreSQL client tools when available:

```bash
pg_isready -h localhost -p 5432
```

`pg_isready` should report that the server is accepting connections. If the command is not on `PATH`, use **SQL Shell (psql)** or the server-status view in your PostgreSQL GUI.

Official downloads and installation instructions vary by operating system:

- Windows installers commonly include PostgreSQL server, pgAdmin, and SQL Shell.
- macOS users may use the official packages or a maintained package manager.
- Linux users normally install from their distribution/PostgreSQL repository and manage a service.

Use the [official PostgreSQL download page](https://www.postgresql.org/download/) for the current instructions. This guide starts at server verification rather than duplicating every OS installer screen.

## 5. PostgreSQL Setup

> Priority: ⭐⭐⭐⭐⭐ MUST KNOW setup

### 5.1 Confirm the server is running

Try:

```bash
pg_isready -h localhost -p 5432
```

Or connect to PostgreSQL's maintenance database as an administrator role (often `postgres` on a local learning installation):

```bash
psql -h localhost -p 5432 -U postgres -d postgres
```

You will be prompted for the administrator password if the server's authentication policy requires it.

In pgAdmin or another GUI, connect to:

```text
Host:     localhost
Port:     5432
Database: postgres
User:     postgres (or your administrator role)
```

### 5.2 Create a dedicated learning role

Run this as a role allowed to create roles and databases. Replace the placeholder with a local-only password of your choice:

```sql
CREATE ROLE jdbc_app
    WITH LOGIN
    PASSWORD 'change_me_local_only';
```

`CREATE USER jdbc_app ...` is also valid; in PostgreSQL it is an alias-like form that gives the role `LOGIN` by default.

Why use a separate role?

- The Java application does not need to connect as a database superuser.
- Ownership and credentials are easier to understand.
- It introduces the least-privilege habit without enterprise complexity.

For this learning project, the role will own its database. In a production system, a migration/owner role and runtime role are often separated further.

### 5.3 Create the database

Still as the administrator:

```sql
CREATE DATABASE jdbc_practice
    OWNER jdbc_app;
```

PostgreSQL does not allow `CREATE DATABASE` inside an ordinary transaction block. Run it as its own command in psql/GUI.

If you run the creation commands twice, “already exists” is expected; do not keep creating duplicate roles/databases.

### 5.4 Connect as the application role

Exit with `\q`, then reconnect:

```bash
psql -h localhost -p 5432 -U jdbc_app -d jdbc_practice
```

Useful psql commands:

| Command | Purpose |
|---|---|
| `\conninfo` | Show the current connection |
| `\dt` | List tables in the current search path |
| `\d students` | Describe the students table after creation |
| `\q` | Quit psql |

Backslash commands are psql commands, not SQL; do not add semicolons to them.

## 6. Database and Table Creation

> Priority: ⭐⭐⭐⭐⭐ MUST KNOW SQL setup

Run the following while connected to `jdbc_practice` as `jdbc_app`.

### 6.1 Students table

```sql
CREATE TABLE students (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    name VARCHAR(100) NOT NULL CHECK (btrim(name) <> ''),
    email VARCHAR(150) UNIQUE NOT NULL,
    age INTEGER NOT NULL CHECK (age BETWEEN 0 AND 150),
    created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP
);
```

| Column | Meaning |
|---|---|
| `id` | PostgreSQL generates a 64-bit identity value; primary key makes it unique/non-null |
| `name` | Required, up to 100 characters, and not whitespace-only |
| `email` | Required and unique; duplicate inserts raise a constraint error |
| `age` | Required integer constrained to a simple learning range |
| `created_at` | Server-generated creation timestamp with time-zone semantics |

The prompt's `BIGSERIAL` example is still common and valid. `GENERATED ... AS IDENTITY` is the modern SQL-standard style and is used here.

Verify:

```sql
SELECT current_database(), current_user;
SELECT id, name, email, age, created_at FROM students;
```

In psql, describe the table separately:

```text
\d students
```

### 6.2 Accounts table for the transaction exercise

```sql
CREATE TABLE accounts (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    owner_name VARCHAR(100) NOT NULL,
    balance NUMERIC(15, 2) NOT NULL CHECK (balance >= 0)
);

INSERT INTO accounts (owner_name, balance)
VALUES
    ('Account A', 1000.00),
    ('Account B', 500.00);
```

`NUMERIC(15,2)` stores exact decimal values. Java will bind the transfer amount with `BigDecimal`, not `double`.

Verify and record the two generated IDs:

```sql
SELECT id, owner_name, balance
FROM accounts
ORDER BY id;
```

If you need to reset only learning data later:

```sql
TRUNCATE TABLE students RESTART IDENTITY;
TRUNCATE TABLE accounts RESTART IDENTITY;

INSERT INTO accounts (owner_name, balance)
VALUES ('Account A', 1000.00), ('Account B', 500.00);
```

`TRUNCATE` is destructive. Run it only against this confirmed practice database, never casually against real data.

Compile the project and then run `Main` with Maven's runtime dependency classpath:

The Exec Maven Plugin is a build tool, not an application dependency. It makes the learning project easy to run while keeping pgJDBC as a normal runtime dependency.

## 8. PostgreSQL JDBC Dependency

> Priority: ⭐⭐⭐⭐⭐ MUST KNOW

The dependency coordinates are:

```text
org.postgresql:postgresql:42.7.13
```

The first Maven build normally performs:

```text
read pom.xml
      ↓
resolve pgJDBC from configured repository (normally Maven Central)
      ↓
download JAR and POM metadata
      ↓
cache under ~/.m2/repository
      ↓
put driver on runtime classpath for exec:java
      ↓
DriverManager discovers PostgreSQL driver
```

Why `runtime` scope is correct here:

- Source code imports `java.sql.*`, which comes from the JDK.
- No source file imports `org.postgresql.*`.
- The vendor driver is required when the application actually connects.

Confirm resolution:

```bash
mvn dependency:tree
```

Look for:

```text
org.postgresql:postgresql:jar:42.7.13:runtime
```

If you later import a pgJDBC-specific class directly, change to the default `compile` scope or deliberately restructure around a standard `DataSource` supplied by configuration.

## 18. Task 8 — Handle SQLException

> Priority: ⭐⭐⭐⭐⭐ MUST KNOW

### Objective

Observe a real database constraint failure and report useful diagnostics without pretending the operation succeeded.

### What to implement

At the console/application boundary, catch `SQLException` and print:

```text
message
SQLState
vendor error code
```

If exceptions are chained, walk `getNextException()`.

### Practice duplicate email

1. Insert a valid student.
2. Insert another student with the exact same email.
3. PostgreSQL's unique constraint should reject it.

Expected PostgreSQL SQLState:

```text
23505 → unique_violation
```

### Concept practiced

Database constraints are the final authority; Java validates and handles, but the database enforces data integrity.

### Hints

```java
for (SQLException current = e;
     current != null;
     current = current.getNextException()) {
    System.err.println(current.getMessage());
    System.err.println(current.getSQLState());
}
```

Do not compare the human-readable English message to decide the error type. SQLState is designed for classification.

### How to verify

- The second insert fails.
- The program prints SQLState `23505`.
- Only the first row exists.
- The DAO does not catch the exception and return a fake successful ID.

Other useful states to recognize during debugging:

| SQLState | Meaning |
|---|---|
| `23502` | not-null violation |
| `23505` | unique violation |
| `23514` | check violation |
| `28P01` | invalid password |
| `3D000` | invalid database |
| `42P01` | undefined table |

|---|---|---|---|
| Connection refused | PostgreSQL stopped, wrong host/port | `pg_isready`; inspect URL/service | Start server or correct host/port |

## 26. Hints

> Priority: ⭐⭐⭐ NICE TO KNOW — use only when stuck

Read hints in order; stop as soon as you can continue yourself.

### Configuration hints

1. Use `DatabaseConfig.class.getClassLoader().getResourceAsStream("database.properties")`.
2. Do not use `new FileInputStream("src/main/resources/...")`; that path breaks when packaged/launched elsewhere.
3. Let environment variables override properties.
4. If no file/env value exists, throw an `IllegalStateException` naming the missing key—but never print a password value.

### DAO hints

1. Store SQL as `private static final String` constants.
2. Let CRUD methods declare `throws SQLException`.
3. A method that opens a connection owns/closes it.
4. `findAll()` creates the list before its resource block and returns it afterward.
5. `mapRow` reads only the current row; it does not call `next()`.
6. A shared helper can bind name, email, and age for both INSERT and UPDATE.

### Generated-key hints

1. Request keys while preparing, not after execution.
2. Verify affected count before reading keys.
3. `getGeneratedKeys()` is a `ResultSet` and begins before its first row.

### Batch hints

1. Bind all three values, then `addBatch()`, once per student.
2. Call `executeBatch()` after the loop.
3. Disable auto-commit before preparing/executing the atomic batch.
4. Commit after success; rollback after `SQLException` or runtime failure.
5. Do not assign generated IDs in this batch task; `create()` separately practices keys.

### Transaction hints

1. Validate IDs/amount before opening the connection.
2. Both prepared statements must be created from the same connection.
3. Require debit count and credit count to equal 1.
4. A safe debit also checks `balance >= amount` in its `WHERE` clause.
5. If rollback fails, attach that failure with `original.addSuppressed(...)`.
6. A directly opened connection closes after the method; a future pooled version must also return clean state.

### Console hints

1. Use a small method per menu action.
2. Parse `nextLine()` values with `Long.parseLong`, `Integer.parseInt`, and `new BigDecimal`.
3. Catch SQL failure at the menu boundary, not inside every DAO method.
4. Use a timestamp in batch email addresses so rerunning does not create accidental duplicates.

```java
package com.example.jdbc.config;

import java.io.IOException;
import java.io.InputStream;
import java.sql.Connection;
import java.sql.DriverManager;
import java.sql.SQLException;
import java.util.Properties;

public final class DatabaseConfig {

    private static final String CONFIG_FILE =
            "database.properties";

    private static final Properties PROPERTIES =
            loadProperties();

    private DatabaseConfig() {
    }

    public static Connection getConnection()
            throws SQLException {
        return DriverManager.getConnection(
                requiredValue("DB_URL", "db.url"),
                requiredValue("DB_USERNAME", "db.username"),
                requiredValue("DB_PASSWORD", "db.password")
        );
    }

    private static Properties loadProperties() {
        Properties properties = new Properties();

        try (InputStream input = DatabaseConfig.class
                .getClassLoader()
                .getResourceAsStream(CONFIG_FILE)) {

            if (input != null) {
                properties.load(input);
            }

            return properties;
        } catch (IOException e) {
            throw new IllegalStateException(
                    "Could not read " + CONFIG_FILE,
                    e
            );
        }
    }

    private static String requiredValue(
            String environmentName,
            String propertyName
    ) {
        String value = System.getenv(environmentName);

        if (value == null || value.isBlank()) {
            value = PROPERTIES.getProperty(propertyName);
        }

        if (value == null || value.isBlank()) {
            throw new IllegalStateException(
                    "Missing configuration: " + propertyName
                            + " (or environment variable "
                            + environmentName + ")"
            );
        }

        // Do not log or print this value; it may be the password.
        // It is not trimmed because a password may contain whitespace.
        return value;
    }
}
```

### 27.6 Complete `StudentDAO.java`

```java
package com.example.jdbc.dao;

import com.example.jdbc.config.DatabaseConfig;
import com.example.jdbc.model.Student;

import java.sql.Connection;
import java.sql.PreparedStatement;
import java.sql.ResultSet;
import java.sql.SQLException;
import java.sql.Statement;
import java.util.ArrayList;
import java.util.List;

public class StudentDAO {

    private static final String INSERT_SQL = """
            INSERT INTO students (name, email, age)
            VALUES (?, ?, ?)
            """;

    private static final String FIND_BY_ID_SQL = """
            SELECT id, name, email, age
            FROM students
            WHERE id = ?
            """;

    private static final String FIND_ALL_SQL = """
            SELECT id, name, email, age
            FROM students
            ORDER BY id
            """;

    private static final String UPDATE_SQL = """
            UPDATE students
            SET name = ?, email = ?, age = ?
            WHERE id = ?
            """;

    private static final String DELETE_SQL =
            "DELETE FROM students WHERE id = ?";

    public long create(Student student) throws SQLException {
        try (Connection connection =
                     DatabaseConfig.getConnection();
             PreparedStatement statement =
                     connection.prepareStatement(
                             INSERT_SQL,
                             Statement.RETURN_GENERATED_KEYS
                     )) {

            bindStudent(statement, student);

            int affectedRows = statement.executeUpdate();
            if (affectedRows != 1) {
                throw new SQLException(
                        "Expected one inserted row, got "
                                + affectedRows
                );
            }

            try (ResultSet keys =
                         statement.getGeneratedKeys()) {
                if (!keys.next()) {
                    throw new SQLException(
                            "Insert succeeded, but no generated ID "
                                    + "was returned"
                    );
                }

                long id = keys.getLong(1);
                student.setId(id);
                return id;
            }
        }
    }

    public Student findById(long id) throws SQLException {
        try (Connection connection =
                     DatabaseConfig.getConnection();
             PreparedStatement statement =
                     connection.prepareStatement(FIND_BY_ID_SQL)) {

            statement.setLong(1, id);

            try (ResultSet resultSet =
                         statement.executeQuery()) {
                return resultSet.next()
                        ? mapRow(resultSet)
                        : null;
            }
        }
    }

    public List<Student> findAll() throws SQLException {
        List<Student> students = new ArrayList<>();

        try (Connection connection =
                     DatabaseConfig.getConnection();
             PreparedStatement statement =
                     connection.prepareStatement(FIND_ALL_SQL);
             ResultSet resultSet = statement.executeQuery()) {

            while (resultSet.next()) {
                students.add(mapRow(resultSet));
            }
        }

        return students;
    }

    public boolean update(Student student) throws SQLException {
        try (Connection connection =
                     DatabaseConfig.getConnection();
             PreparedStatement statement =
                     connection.prepareStatement(UPDATE_SQL)) {

            bindStudent(statement, student);
            statement.setLong(4, student.getId());

            return statement.executeUpdate() == 1;
        }
    }

    public boolean delete(long id) throws SQLException {
        try (Connection connection =
                     DatabaseConfig.getConnection();
             PreparedStatement statement =
                     connection.prepareStatement(DELETE_SQL)) {

            statement.setLong(1, id);
            return statement.executeUpdate() == 1;
        }
    }

    public int[] batchInsert(List<Student> students)
            throws SQLException {
        if (students.isEmpty()) {
            return new int[0];
        }

        try (Connection connection =
                     DatabaseConfig.getConnection()) {
            connection.setAutoCommit(false);

            try {
                int[] updateCounts;

                try (PreparedStatement statement =
                             connection.prepareStatement(INSERT_SQL)) {
                    for (Student student : students) {
                        bindStudent(statement, student);
                        statement.addBatch();
                    }

                    updateCounts = statement.executeBatch();
                }

                connection.commit();
                return updateCounts;
            } catch (SQLException | RuntimeException e) {
                rollback(connection, e);
                throw e;
            }
        }
    }

    private static void bindStudent(
            PreparedStatement statement,
            Student student
    ) throws SQLException {
        statement.setString(1, student.getName());
        statement.setString(2, student.getEmail());
        statement.setInt(3, student.getAge());
    }

    private static Student mapRow(ResultSet resultSet)
            throws SQLException {
        return new Student(
                resultSet.getLong("id"),
                resultSet.getString("name"),
                resultSet.getString("email"),
                resultSet.getInt("age")
        );
    }

    private static void rollback(
            Connection connection,
            Throwable originalFailure
    ) {
        try {
            connection.rollback();
        } catch (SQLException rollbackFailure) {
            originalFailure.addSuppressed(rollbackFailure);
        }
    }
}
```

The batch method is explicitly transactional. It does not retrieve generated IDs; the single-row `create` method separately practices that concern.

```java
            """;

    private static final String BALANCE_SQL =
            "SELECT balance FROM accounts WHERE id = ?";

    public void transfer(
            long fromId,
            long toId,
            BigDecimal amount
    ) throws SQLException {
        BigDecimal exactAmount =
                validateTransfer(fromId, toId, amount);

        try (Connection connection =
                     DatabaseConfig.getConnection()) {
            connection.setAutoCommit(false);

            try {
                try (PreparedStatement debit =
                             connection.prepareStatement(DEBIT_SQL);
                     PreparedStatement credit =
                             connection.prepareStatement(CREDIT_SQL)) {

                    debit.setBigDecimal(1, exactAmount);
                    debit.setLong(2, fromId);
                    debit.setBigDecimal(3, exactAmount);

                    if (debit.executeUpdate() != 1) {
                        throw new SQLException(
                                "Debit failed: source is missing "
                                        + "or balance is insufficient"
                        );
                    }

                    credit.setBigDecimal(1, exactAmount);
                    credit.setLong(2, toId);

                    if (credit.executeUpdate() != 1) {
                        throw new SQLException(
                                "Credit failed: destination account "
                                        + "is missing"
                        );
                    }
                }

                connection.commit();
            } catch (SQLException | RuntimeException e) {
                rollback(connection, e);
                throw e;
            }
        }
    }

    public BigDecimal findBalance(long accountId)
            throws SQLException {
        try (Connection connection =
                     DatabaseConfig.getConnection();
             PreparedStatement statement =
                     connection.prepareStatement(BALANCE_SQL)) {

            statement.setLong(1, accountId);

            try (ResultSet resultSet =
                         statement.executeQuery()) {
                return resultSet.next()
                        ? resultSet.getBigDecimal("balance")
                        : null;
            }
        }
    }

    private static BigDecimal validateTransfer(
            long fromId,
            long toId,
            BigDecimal amount
    ) {
        if (fromId <= 0 || toId <= 0) {
            throw new IllegalArgumentException(
                    "Account IDs must be positive"
            );
        }

        if (fromId == toId) {
            throw new IllegalArgumentException(
                    "Source and destination must differ"
            );
        }

        if (amount == null || amount.signum() <= 0) {
            throw new IllegalArgumentException(
                    "Amount must be positive"
            );
        }

        try {
            return amount.setScale(2, RoundingMode.UNNECESSARY);
        } catch (ArithmeticException e) {
            throw new IllegalArgumentException(
                    "Amount may have at most two decimal places",
                    e
            );
        }
    }

    private static void rollback(
            Connection connection,
            Throwable originalFailure
    ) {
        try {
            connection.rollback();
        } catch (SQLException rollbackFailure) {
            originalFailure.addSuppressed(rollbackFailure);
        }
    }
}
```

Because these are directly opened connections that close immediately, the methods do not need to restore auto-commit for reuse. A future pooled implementation must return connections with clean state, while still committing or rolling back before close.

### 27.8 Complete `Main.java`

```java
package com.example.jdbc;

import com.example.jdbc.config.DatabaseConfig;
import com.example.jdbc.dao.StudentDAO;
import com.example.jdbc.model.Student;
import com.example.jdbc.service.AccountTransferService;

import java.math.BigDecimal;
import java.sql.Connection;
import java.sql.SQLException;
import java.util.List;
import java.util.Scanner;

public class Main {

    private final Scanner scanner = new Scanner(System.in);
    private final StudentDAO studentDAO = new StudentDAO();
    private final AccountTransferService transferService =
            new AccountTransferService();

    public static void main(String[] args) {
        if (!testConnection()) {
            return;
        }

        new Main().runMenu();
    }

    private static boolean testConnection() {
        try (Connection connection =
                     DatabaseConfig.getConnection()) {
            String database = connection
                    .getMetaData()
                    .getDatabaseProductName();

            System.out.println(
                    "Connected successfully to " + database
            );
            return true;
        } catch (SQLException e) {
            printSqlException(e);
            return false;
        } catch (RuntimeException e) {
            System.err.println(
                    "Configuration error: " + e.getMessage()
            );
            return false;
        }
    }

    private void runMenu() {
        while (true) {
            printMenu();
            String choice = scanner.nextLine().trim();

            try {
                switch (choice) {
                    case "1" -> addStudent();
                    case "2" -> findStudent();
                    case "3" -> listStudents();
                    case "4" -> updateStudent();
                    case "5" -> deleteStudent();
                    case "6" -> batchInsert();
                    case "7" -> transferMoney();
                    case "0" -> {
                        return;
                    }
                    default ->
                            System.out.println("Unknown option.");
                }
            } catch (SQLException e) {
                printSqlException(e);
            } catch (IllegalArgumentException e) {
                System.err.println(
                        "Invalid input: " + e.getMessage()
                );
            }
        }
    }

    private void addStudent() throws SQLException {
        Student student = readStudentWithoutId();
        long id = studentDAO.create(student);
        System.out.println("Created student with ID " + id);
    }

    private void findStudent() throws SQLException {
        Student student =
                studentDAO.findById(readLong("ID: "));

        System.out.println(
                student == null
                        ? "Student not found."
                        : student
        );
    }

    private void listStudents() throws SQLException {
        List<Student> students = studentDAO.findAll();

        if (students.isEmpty()) {
            System.out.println("No students.");
            return;
        }

        students.forEach(System.out::println);
    }

    private void updateStudent() throws SQLException {
        long id = readLong("ID to update: ");
        Student student = readStudentWithoutId();
        student.setId(id);

        System.out.println(
                studentDAO.update(student)
                        ? "Updated."
                        : "Student not found."
        );
    }

    private void deleteStudent() throws SQLException {
        boolean deleted =
                studentDAO.delete(readLong("ID to delete: "));

        System.out.println(
                deleted ? "Deleted." : "Student not found."
        );
    }

    private void batchInsert() throws SQLException {
        long suffix = System.currentTimeMillis();

        List<Student> students = List.of(
                new Student(
                        "Batch A",
                        "batch.a." + suffix + "@example.com",
                        20
                ),
                new Student(
                        "Batch B",
                        "batch.b." + suffix + "@example.com",
                        21
                ),
                new Student(
                        "Batch C",
                        "batch.c." + suffix + "@example.com",
                        22
                ),
                new Student(
                        "Batch D",
                        "batch.d." + suffix + "@example.com",
                        23
                )
        );

        int[] counts = studentDAO.batchInsert(students);
        System.out.println(
                "Batch completed for "
                        + counts.length + " statements."
        );
    }

    private void transferMoney() throws SQLException {
        long from = readLong("From account ID: ");
        long to = readLong("To account ID: ");
        BigDecimal amount =
                new BigDecimal(readRequired("Amount: "));

        System.out.println(
                "Before: from="
                        + transferService.findBalance(from)
                        + ", to="
                        + transferService.findBalance(to)
        );

        transferService.transfer(from, to, amount);

        System.out.println("Committed.");
        System.out.println(
                "After: from="
                        + transferService.findBalance(from)
                        + ", to="
                        + transferService.findBalance(to)
        );
    }

    private Student readStudentWithoutId() {
        String name = readRequired("Name: ");
        String email = readRequired("Email: ");
        int age = Integer.parseInt(readRequired("Age: "));

        return new Student(name, email, age);
    }

    private long readLong(String prompt) {
        return Long.parseLong(readRequired(prompt));
    }

    private String readRequired(String prompt) {
        System.out.print(prompt);
        String value = scanner.nextLine().trim();

        if (value.isEmpty()) {
            throw new IllegalArgumentException(
                    "Value cannot be blank"
            );
        }

        return value;
    }

    private static void printSqlException(SQLException e) {
        for (SQLException current = e;
             current != null;
             current = current.getNextException()) {
            System.err.printf(
                    "Database error: %s | SQLState=%s | code=%d%n",
                    current.getMessage(),
                    current.getSQLState(),
                    current.getErrorCode()
            );
        }
    }

    private static void printMenu() {
        System.out.println("""

                === Student Management ===
                1. Add student
                2. Find student by ID
                3. List students
                4. Update student
                5. Delete student
                6. Batch insert sample students
                7. Transfer money (transaction exercise)
                0. Exit
                """);

        System.out.print("Choose: ");
    }
}
```

```text
Main
 │
 ▼
StudentDAO / AccountTransferService
 │
 ▼
PreparedStatement
 │
 ▼
JDBC Connection
 │
 ▼
PostgreSQL JDBC Driver

 ▼
```

```text
PostgreSQL
    ↓
ResultSet
    ↓

    ↓
Student object
    ↓
```

Atomic transfer:

```text
one Connection with auto-commit disabled
       ├── debit affects exactly one row
       ├── credit affects exactly one row
       └── both succeed → commit
                any failure → rollback
```
